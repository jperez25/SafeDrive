# Git rules
- Always ask the user for confirmation before every `git commit` and every `git push`. Never do either on your own.
- Every commit message starts with the project key `QNTA-<n>`, where `<n>` is the ticket number, e.g. `QNTA-12: add trip event contract`. If the ticket number is unknown, ask the user.
- Never commit `.env` or other secrets.
